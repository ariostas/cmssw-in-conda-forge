# Reconstruction: tracking, vertexing, muon reconstruction and the rest of the geometry.
#
# Regenerate with
#   python3 cmssw-notes/analysis/scripts/reach.py --target \
#     RecoTracker,RecoVertex,RecoMuon,TrackingTools,RecoLocalTracker,CommonTools,\
#     Geometry,MagneticField,TrackPropagation
# which takes those subsystems and adds exactly their dependency closure, minus whatever the
# four layers below already own. That is deliberately not the greedy --layers partition: asked
# for the same number of translation units it returns a slice of 79 subsystems, from Fireworks
# to TopQuarkAnalysis, that does not deliver anything in particular.
#
# The list is then closed over the headers CMSSW includes without declaring them in a
# BuildFile, walking the include graph out of the files SCRAM actually compiles
# (analysis/scripts/includes.py). That adds 26 packages here, mostly Alignment and
