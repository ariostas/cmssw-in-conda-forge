# Raw data to physics objects: the RAW unpackers, calorimeter and muon local reconstruction,
# e/gamma, particle flow, jets and b-tagging where they can be built, and the calibration
# packages those read.
#
# Regenerate with
#   python3 cmssw-notes/analysis/scripts/reach.py --target \
#     EventFilter,RecoLocalCalo,RecoLocalMuon,RecoEcal,RecoEgamma,RecoParticleFlow,RecoJets,\
#     RecoMET,RecoBTag,RecoBTau,RecoHI,RecoPPS,RecoLuminosity,RecoLocalFastTime,RecoMTD,\
#     RecoHGCal,RecoTICL,RecoTauTag,RecoTracker,RecoCaloTools,JetMETCorrections,\
#     CalibCalorimetry,CalibTracker,CalibMuon,CalibPPS,CalibFormats,L1Trigger,L1TriggerConfig,\
#     Configuration
# and close it over undeclared includes with analysis/scripts/includes.py. Four packages are
# added by hand for the configuration the test loads: HeterogeneousCore/Common and ROCmCore
# (Configuration.StandardSequences.Accelerators_cff imports them), SimCalorimetry/
# EcalSimProducers and TauAnalysis/MCEmbeddingTools (the ECAL rechit fragments import them).
#
# Left out because they cannot be built: the MET producers, whose beam-halo code includes
# L1Trigger/CSCTrackFinder and so needs the unlicensed `utm`; most of the L1 emulator, for
# the same reason; and whatever needs TensorFlow or the Triton client (RecoEcal/
# EgammaClusterAlgos, and with it the PF superclusters). Undeclared includes count as
# dependencies here: reach.py merges analysis/scripts/include_graph.py's output.
